## Portable profile v1

A profile contains a world namespace, stable entity ID, kind (individual or organization), effective date, label, native rules namespace, and properties. Each property has value, unit/scale, classification, and an explanation or exact source reference. Keep missing properties explicitly unresolved; never treat unknown as zero. A dated source reference uses the existing source compiler contract; a narrative evidence reference is not proof of a numeric interpretation.

Motivations, commitments, capabilities, resources and directed relationships are separate property namespaces. Store native game-system values as-is; normalization requires a reviewed mapping, not a guessed conversion. Generic behavioral weights are hypothetical unless canon explicitly defines them. Never infer behavior from demographic membership.

Compile reviewed nonnegative integer source records with the existing resolver; other native value types can be recorded as reviewed hypothetical literals in this increment. Narrative evidence supports review but does not automatically derive values. Snapshot digest binds exact initialization and references. Recompilation with unchanged source and inputs is deterministic; future session decisions and dialogue are separate.

This increment validates and compiles profiles only. No automatic source mining, actor policy, cross-framework attribute conversion, or gameplay integration is claimed.
